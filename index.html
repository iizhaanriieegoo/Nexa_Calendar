📲 Instalar NEXA Calendar

Puedes instalar NEXA Calendar para abrirla como una aplicación independiente.

iPhone / iPad
1. Abre NEXA Calendar en Safari.
2. Pulsa Compartir.
3. Selecciona Añadir a pantalla de inicio.
4. Pulsa Añadir.
Ordenador / Android
Si el navegador permite instalación directa, aparecerá el botón Instalar ahora.
